# 红锚哨兵 V3.0 五画像交叉测试

测试方式：对照现有雷达首页、十四维双轨面板和闸刀指挥台，各走一轮主路径。每名画像只记两处会挡住任务的界面问题。下面的改动已落到代码里。

## 画像 1 · 资深安全工程师

1. 局域网清单里直接露出邻居硬件地址。审计员会把它当成扫描留痕，而不是安全结论。
2. 补丁哈希写在账本备注里，首页没有地方导出脱敏日志，也没有提交建议的入口。

改动：清单里的硬件地址改为“已隐藏”。雷达页增加极客反馈，导出前去掉地址和邮箱。

## 画像 2 · 企业开发

1. 十四维和扫描结果不能导出，硬件测试记录留在浏览器里。
2. 时序覆写一次只能改一个维度，批量修正基线要重复点十几次。

改动：增加 CSV 与 JSON 导出。双轨面板增加按行批量写入当前时点。

## 画像 3 · 业务工程师

1. 首页没有拦截和危急数量，看不出这周哨兵做了什么。
2. 没有可带走的评估报告，无法贴进生产例会。

改动：增加威胁统计。支持下载一页文字版 PDF 报告。

## 画像 4 · 本地模型玩家

1. 推理提示词、扫描间隔和界面主色都写死，微调模型接不进去。
2. 模型没开时，失败原因混着英文 `fetch failed`，不知道下一步该启动什么。

改动：高级设置可附加提示词、选择扫描间隔和主色。模型连不上时改为中文说明。

## 画像 5 · 家庭用户

1. 首页先看到钢印和三级术语，没有一颗能看懂的体检按钮。
2. 十四维名称没有对应的生活语言，缺氧和未亮明身份都像内部代号。

改动：增加“一键体检”和“一键标记隔离”。体检结果用一句话说明。一键修复只把没有金印的信号记入本地隔离账本，不向别人的设备下发补丁。
